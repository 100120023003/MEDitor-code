# Contributing

Bug reports and focused pull requests are welcome.

1. Do not include benchmark data, model weights, credentials, patient
   information, or generated traces that you are not permitted to share.
2. Keep changes scoped and document behavior that affects reported results.
3. Run `python -m unittest discover -s tests -v` before opening a pull request.
4. Include a small regression test for bug fixes when practical.

Use GitHub Issues for reproducible problems and include the Python version,
command-line arguments with secrets removed, and the shortest useful error
trace.
